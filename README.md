A fairly basic test of trying to upload a react native app project to github pages.
The 'objective' of sorts behind this small personal project over the weekend was to test a more interactive way to display prototype apps when putting practice projects on github. 
I am not the most familiar with react native portfolios, but from what I have seen the main trend is to upload the react native project with screenshots and recordings of the app being used, and I was wondering if I could make an interactive web version similar to the local web display a user can make  in terminal by using the command "press w to see in web" and have a localhost page displayed.
I wanted to do this because I felt for some practice apps I was not necessaily going to upload them on the app store but I still wanted to 'display' them in a more interactive manner.

But since I hadn't exactly followed an explicit guide of how this hypothetical would be done in 2026 this project didn't go quite as easily as I had hoped, but any feedback would be great!
So far I will stick to the tried and true methods of uploading practice react native apps on github.
